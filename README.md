### Details of test cases
Unit testing for classes:

1. Create a test .cpp source file for every class 

2. Create a class object for testing
   
4. Compile source file into .o
   
5. Compile the test file and object file with g++

6. Run test

Unit testing for validation functions:

Create .cpp test file for addVehicle.cpp file

TEST_CASE 2 functions that validate a parameter and return a Boolean

Test for passing and failing parameters

Unit testing for vectors:

Create .cpp test file for addVehicle.cpp file

Test different SCENARIOs where an element is added, multiple elements are added, elements are removed, vector is cleared

Test that all scenarios pass
